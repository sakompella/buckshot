# The held briefcase item is public

While players grab items from the briefcase, the item a player has drawn and not yet placed is visible to every seat. The real game shows it on every screen, so the public board carries it (a seat's briefcase is not grabbing, grabbing or holding an item), and the agent view lists it as `holding`. Hiding it would give an agent less than a person at the table has. It is public, so it is not a secret in the sense of ADR-0022.
